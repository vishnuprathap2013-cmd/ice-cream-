FALOODA HUT — STATIC HOSTING BUNDLE

Contents:
- index.html
- 8 supplied food photos in WebP format with PNG fallbacks

Quickest hosting option (Netlify Drop):
1. Extract falooda-hut-hosting.zip.
2. Sign in to Netlify and open https://app.netlify.com/drop
3. Drag the extracted falooda-hut-hosting folder onto the page.
4. Netlify will provide a public URL. Add a custom domain later from Site settings > Domain management.

Other static hosting options:
- Vercel: import this folder/repository as a static site; no build command is needed and the output directory is the project root.
- GitHub Pages: commit the files to a repository, then enable Pages for the main branch and root folder.

Before public launch:
- Confirm the sample flavour list, prices, and availability with Falooda Hut.
- The contact and newsletter forms are demo-only and do not send or store submissions; connect a form service/backend before relying on them.
- Online-order buttons use the Google order link supplied for the original listing.
